Water-table exchange in WatsubMod

External-water-table and tile exchange are Darcy-type boundary transfers, activated by depth and wetness tests. This description distinguishes the activation gates, driving potentials, accepted water volumes, signed face storage, and hourly depth updates.

Reviewed 14 October 2026 against the working tree based on 0cb20d7c, including current uncommitted changes in WatsubMod and RedistMod. Equations describe the implementation; design intentions and unresolved concerns are identified separately. No model code was changed for this page.

1. Coordinate system, units, and signs

Depth z increases downward. Use the same column depth coordinate for layer edges, midpoints, and water-table levels; elevation and surface-depth adjustments are applied upstream. Matric potentials are normally negative. Write g = mGravAccelerat ≈ 0.00981 MPa m⁻¹ for the water-head-to-potential conversion.

Layer overlap and macropore water surface

clip(x,a,b) = min(b,max(a,x))
f(z*)       = clip((zᵦ − z*)/h, 0, 1)
              = 1                 if z* ≤ zₜ       (whole layer below target)
              = (zᵦ − z*)/h       if zₜ < z* < zᵦ
              = 0                 if z* ≥ zᵦ       (whole layer above target)

z_mac = zᵦ − h (W_mac + I_mac)/V_mac     when V_mac > numerical threshold
        zᵦ                             otherwise

The code weights discharge by 1 − f and recharge by f. These are geometric fractions, not saturation fractions. A partly intersected layer is still subject to midpoint activation tests; a nonzero overlap alone does not activate transfer. The macropore surface estimate includes ice volume, while the drained donor volume is liquid water.

2. Input modes and substep dispatch

readimod reads grid IDTBLG at loc=1 and initially assigns that mode to all initialized cells. Restarts and selected-cell management events can subsequently make modes differ.

IDWaterTableNatural external tableTile
0DisabledDisabled
1StationaryDisabled
2MobileDisabled
3StationaryEnabled, stationary
4MobileEnabled, mobile

DTBLIG supplies natural depth, DTBLDIG tile depth, and DTBLGG the relative slope b. Each face supplies s from RCHG{N,E,S,W}UG and D from RCHG{N,E,S,W}TG. RCHGDG supplies the bottom multiplier. A zero face multiplier disables both natural and tile exchange on that face.

  1. Internal Darcy transport executes first and updates a remaining micropore budget, VLWatMicP2_vr.
  2. XBoundaryFlowM calculates layer pore space and discharge flags, then visits external west/east/north/south faces and the bottom face. Direction processing begins at FlowDirIndicator_col = grid_mode; mode 3 processes only vertical flow.
  3. The caller currently selects VertBoundaryDrainM when (IDWaterTable=0 OR N=3) AND s≠0. Otherwise it adds natural discharge, tile discharge, and natural recharge when their respective conditions hold.
  4. Face divergences are collected by Summarize3DFlowM and applied to water and heat storage by UpdateSoilMoistTempM.
Intended vertical role versus current caller. VertBoundaryDrainM is intended for vertical drainage, but the IDWaterTable=0 clause currently permits lateral calls. The equations below document that actual branch rather than silently treating it as vertical-only. With mode 3, no lateral natural-table or tile exchange occurs.

Source: readimod, watsub and XBoundaryFlowM.

3. Activation is separate from hydraulic driving force

Natural micropore discharge: default branch

Start with flag = false.
Require mode ≠ 0, zₘ < zₑ, and zₘ < zₑ + ψₛ,L/g.
The last test is equivalently ψₛ,L > g(zₘ − zₑ).
For each deeper layer j:
  z_eq,j = zₑ + ψₛ,j/g
  only if zₘ,j < z_eq,j, disable the flag when
    [ψ₁,j ≤ g(zₘ,j − z_eq,j) AND j ≠ bottom] OR zₘ,j > zₐ.

The source-layer gate uses ψₛ, not its current ψₘ. It is therefore inaccurate to describe that initial gate as a direct current-wetness test. Actual driving potential is calculated later. The deeper-layer restriction is nested inside zₘ,j < z_eq,j; there is no universal source-layer active-depth check in this branch.

Natural micropore discharge: use_ecosys_drainage

Require mode ≠ 0, zₘ < zₑ, and ψₘ,L > ψ_threshold,L.
For every deeper j with zₘ,j < zₑ:
  disable if ψₘ,j ≤ ψ_threshold,j OR zₘ,j > zₐ.

ZmOutletWetnessPotential searches the vertical K table for its first entry below 0.1 Ksat and converts the preceding wetter entry’s θ to matric potential. If the threshold cannot be resolved, it retains ψₛ. This is a conductivity-derived gate, not a claim that every permitted layer is fully saturated.

Tile micropore discharge

Require mode ≥ 3, zₘ < z_d, and zₘ < z_d + ψ₁,L/g.
The last test is equivalently ψ₁,L > g(zₘ − z_d).
For deeper j, use z_eq,j = z_d + ψₛ,j/g and the default deeper-layer test.

Unlike the default natural gate, the tile source gate uses ψ₁,L. Tile activation does not switch to the conductivity-derived gate when use_ecosys_drainage is true, even though tile flux then uses the legacy driving-potential branch.

Macropore discharge

The natural gate requires mode ≠ 0, z_mac < zₑ, and positive liquid macropore storage; the tile gate requires mode ≥ 3 and z_mac < z_d. Default natural and tile configuration reject discharge if a deeper layer above the target has no macropore capacity. The legacy natural branch returns before this deeper-capacity scan and does not explicitly test LMacPoreOff. In the current default branch, LMacPoreOff is checked after micropore configuration, so it no longer suppresses natural micropore discharge.

Source: Config4WaterTableDrain, ZmOutletWetnessPotential, Config4TileDrainage.

4. Discharge to the natural table or tiles

Let target z* be zₑ for natural discharge or z_d for tiles. The clipped depth term simplifies exactly:

(z−z*)−max(0,z−zi)=min(z,zi)−z*

Thus the internal table caps the depth contributing to gravitational head. The term is not a direct calculation of saturated layer volume; that geometric weighting is supplied separately by 1 − f.

Directional slope correction:
  δ_N = ξ · ½ g · SLOPE_N · ℓ_N · (1 − b)

Micropore, default:
  p₀ = min(0, −ψₘ − 0.03ψₒ + g[min(zₘ,zᵢ) − z*])
  K  = K_N,sat

Micropore, use_ecosys_drainage (natural AND tile):
  p₀ = min(0, −ψₘ + ψₛ + g[min(zₘ,zᵢ) − z*])
  θ  = max(θ_air-dry, min(porosity, W_mic/V_soil-mic))
  k  = max(1,min(100,101 − int(100θ/porosity)))
  K  = K_N(θ)

Macropore, either switch setting:
  p₀ = g[min(z_mac,zᵢ) − z*]
  K  = K_mac

For each domain:
  p = p₀ − δ_N  if p₀ < 0; otherwise p = p₀
  q_raw = p K A_N (1 − f(z*)) s Δt / (D + 1 m)

Interpretation as a potential difference

ψ_eq = g[min(zₘ,zᵢ) − z*]
Default micropore potential before slope correction:
  p₀ = min(0, ψ_eq − ψₘ − 0.03ψₒ)
Legacy micropore potential before slope correction:
  p₀ = min(0, ψ_eq + ψₛ − ψₘ)

With zero osmotic and slope contributions, the default branch produces outflow when ψₘ > ψ_eq: the soil is wetter than the target equilibrium. At ψₘ = ψ_eq its flux potential is zero. The legacy branch shifts this threshold by ψₛ and changes conductivity at the same time. This explains the flux equation; it does not replace the distinct activation gates in section 3. The source uses a prescribed reservoir level and finite conductance rather than solving an atmospheric-pressure seepage face.

The written D+1 is interpreted as a one-metre offset if D is a distance. For dimensionless s, Darcy volume requires K in m² MPa⁻¹ h⁻¹: MPa × K × m² / m × h = m³. This is a dimensional interpretation of the equation; the existing K and boundary-rate metadata are inconsistent with it.

Accepted micropore discharge: q_mic = q_raw              (no donor cap)

Accepted macropore discharge:
  B_mac = α W_mac + F_vertical,in − F_vertical,out
  q_mac = max(q_raw, min(0, −B_mac))

Stored face contribution: F = ξ q
Drainage diagnostic increment: ΔQDrain = −q

The macropore cap includes net vertical macropore flow already stored in the face arrays, but does not subtract earlier lateral or natural/tile withdrawals. Because the negative-part clip occurs before the slope correction, the final p is not guaranteed to remain nonpositive. The macropore potential has no initial negative-part clip at all. “Discharge” is therefore a pathway name, not an unconditional guarantee of sign.

Effect of the legacy switch. The shared discharge routine applies its legacy potential and K(θ) to tiles as well as natural outlets. Upstream SoilHydroParaMod also sets SRP to 0.67 and derives air-entry/saturation thresholds from a 10% conductivity crossing. The switch consequently affects internal hydraulics too; it is not solely a boundary-flux change.

Worked discharge example

Take a whole layer above its target: zₘ = 1 m, z* = 2 m, zᵢ = 1.2 m, ψₘ = −0.002 MPa, ψₒ = 0, ψₛ = −0.001 MPa, δ_N = 0, A_N = 1 m², D = 1 m, s = 1, and Δt = 0.99999/30 h. Prescribe Ksat = 1 and K(θ) = 0.2 in the Darcy units above. Assume the appropriate activation gate passes.

BranchDriving potentialColumn transfer q

5. Recharge from the natural table

Only zₑ supplies recharge; there is no tile-to-soil recharge routine. Micropore recharge requires zₘ ≥ zₑ, zₐ > zₑ, zₘ < zₐ, positive stored micropore air volume, a nonzero face multiplier, and either positive working air space or a non-soil layer. Macropore recharge instead requires z_mac > zₑ, zₐ > zₑ, zₘ < zₐ, and positive macropore air space.

Micropore:
  u₀ = max(0, −ψₘ − 0.03ψₒ + g(zₘ − zₑ))
  K  = K_N,sat                         even when use_ecosys_drainage is true
Macropore:
  u₀ = −0.03ψₒ + g(z_mac − zₑ)
  K  = K_mac

u = u₀ + δ_N  if u₀ > 0; otherwise u = u₀
q_raw = u K A_N f(zₑ) s Δt / (D + 1 m)

Soil micropores:
  q_mic = min(q_raw, C_mic)
  q_aux = min(q_raw, C_aux)             separate wetting-front capacity
Non-soil micropores:
  q_mic = q_aux = q_raw                working-air cap bypassed
Macropores:
  q_mac = min(q_raw, C_mac)

After each face:
  C_mic ← C_mic − q_mic; C_aux ← C_aux − q_aux; C_mac ← C_mac − q_mac

Working capacities are initialized once per layer from pore capacity minus liquid and ice, then reduced as faces are visited. Soil recharge therefore shares a capacity budget among faces. It is not an aggregate budget for all internal and external processes. Neither final potential nor accepted transfer is clipped from below after the slope correction, so positivity should be interpreted conditionally. q_aux updates an auxiliary representation of the same micropore water, not another physical pool.

Worked recharge and sign example

Let zₘ = 2 m, zₑ = 1 m, ψₘ = −0.003 MPa, ψₒ = −0.01 MPa, δ_N = 0, f = 1, Ksat = 1, A_N = 1 m², D = 1 m, s = 1, and Δt = 0.99999/30 h. Then u = 0.003 + 0.0003 + 0.00981 = 0.01311 MPa, giving q_raw ≈ 0.2185 L. With only 0.1 L working air space, accepted recharge is 0.1 L. The remaining capacity becomes zero; a subsequent face cannot add more positive water through that capacity.

On an east face ξ = −1, so F = −0.0001 m³. On a west face ξ = +1, F = +0.0001 m³. Both mean the column gains 0.0001 m³ and both add −0.0001 m³ to QDischarg2WTBL_col.

Source: RechargeFromExtWaterTBL.

6. Vertical free drainage and the mode-zero branch

θ = max(θ_air-dry, min(porosity, W_mic/V_soil-mic))
K_mic = K_N(θ) × RainEkReducedKsat   at the upper active layer; otherwise K_N(θ)
K_mac = HydroCondMacP1_vr

For domain p ∈ {mic,mac}:
  F_raw,p = −ξ s Δt D g |SLOPE_N| A₃ K_p
  F_p = AZERO(clip(F_raw,p, −αW_p, +αW_p))
  q_p = ξF_p

At the bottom, ξ = −1, D = 1, and initialization sets SLOPE₃ = −1; thus positive controls produce outward drainage. Each call caps liquid removal at αW_p. The micropore surface reduction can also affect bottom flow in a single-active-layer column. The formula is quoted as implemented: its dimensional distance-factor interpretation should not be conflated with the divided-distance water-table formula.

Under the current mode-zero lateral branch, the same routine uses footprint area A₃ and multiplies by D, even for N = 1 or 2. This differs from the directional-area, divided-distance exchange equations. It is an implementation/design mismatch to resolve in the caller; no model correction is made here.

Source: VertBoundaryDrainM and XBoundaryFlowM.

7. Water and heat accounting

For every boundary contribution:
  F = ξq
  face heat H = c_w T_local F
  column heat gain = ξH = c_w T_local q

Discharge/free-drainage accumulators:
  ΔQDrain = ΔQDrainM = ΔQDrain_cum = ΔQDrainloss = −q
  ΔHeatDrain = −c_w T_local q
Recharge accumulators:
  ΔQDischarg2WTBL = ΔQDischarM = −q
  ΔHeatDischar = −c_w T_local q

Net layer water change from face transport:
  ΔW = Σ_N (F_N,upstream − F_N,downstream)
Then add infiltration, pore-domain exchange, phase change and irrigation
in their respective storage updates; they are not all represented by ΔW.

The water-table helpers use the local soil temperature for both discharge and recharge; no separately prescribed external-reservoir temperature appears in those heat terms. VertBoundaryDrainM selects the donor by face sign; for ordinary outward west/north drainage its indexed donor is still the interior cell. The column energy update combines advective heat with conductive and phase-change terms and divides by the updated heat capacity.

Boundary discharge and recharge are diagnostics for opposite named pathways; their sum need not represent the entire hydrological budget. Natural and tile discharge both enter QDrain; natural recharge enters QDischarg2WTBL with a negative sign. They remain separate in the mobile-table update below.

Source: Summarize3DFlowM and UpdateSoilMoistTempM.

8. How table depths and modes change

Let z₀ be NaturalWaterTableDepzTopoC_col, d₀ be TileWaterTableLocDepz_col, e_s be CumDepz2LayBottom_vr(NU−1,…), A be footprint area, R be the hour’s QDischarg2WTBL_col, and λ = 0.00167 per hourly invocation.

Hour1 resets:
  modes 0,1,3: zₑ ← z₀
  modes 2,4:   zₑ ← z₀ + e_s
  modes 3,4:   z_d ← d₀

Redist, modes 2 and 4 (assignment order matters):
  zₑ ← z₀ + e_s
  zₑ ← zₑ − R/A − λ(zₑ − z₀ − e_s)
     = z₀ + e_s − R/A                relaxation term evaluates to zero

Redist, mode 4:
  z_d ← z_d − R/A − λ(z_d − d₀)
       = d₀ − R/A                   if no intervening event changed z_d

The natural-table update has no retained previous-depth term. Hour1 also resets tile depth each hour, so tile relaxation generally has no accumulated memory across hours. Since R < 0 means recharge into soil, −R/A is positive: that booked recharge increases the external depth. Neither natural nor tile discharge booked in QDrain drives this update, and no specific yield appears. These are implementation equations, not a groundwater storage balance inferred from process names.

At solar noon, event 23, with management depth d and Δe = ALTZ − ALT:
  NatWtblDepz ← d + e_s
  z₀ ← NatWtblDepz − Δe(1 − b)
  zₑ ← z₀ + e_s                     e_s enters twice through these assignments
  IDWaterTable is unchanged.

At solar noon, event 24:
  WtblDepzTile ← d + e_s
  d₀ ← max(0, WtblDepzTile − Δe(1 − b)); z_d ← d₀
  mode 1 → 3; mode 2 → 4; modes 0,3,4 remain unchanged.

These events are read into the selected grid rectangle. Event 24 does not turn mode zero into an enabled water-table mode. Mode 4 then executes its mobile update in the same routine. An internal water table zᵢ is diagnosed separately from soil water/ice and air volume by DiagWaterTableDepZi; it is not identical to zₑ and is not the externally supplied boundary condition.

Source: Hour1Mod, ModifyExWTBLByDisturbance, ReadTillageFile, DiagWaterTableDepZi.

9. Applying the equations to the Fen example

The actual grid NetCDF selected by FenStordIsland.namelist has IDTBLG = 1, DTBLIG = 0 m, north/south multipliers s = 1 with D = 1 m, east/west multipliers zero, and RCHGDG ≈ 0.1. The namelist uses grid_mode = 1.

In the initialized reference geometry, ordinary soil midpoints below zₑ = 0 cannot pass the source-layer natural discharge gate zₘ < zₑ. Those layers can instead receive recharge when active-depth and pore-space conditions pass. North and south share each layer’s working air-space budget; they do not each get an independent full capacity. Bottom drainage uses a nonzero multiplier and remains a separate pathway. Surface shifts and management changes must be evaluated in the same adjusted depth coordinate before extending this interpretation to later states.

Checked directly: Fen namelist and selected grid NetCDF.

10. Qualifications and verification

  • updated sourceMacropores-off behavior. The old default-branch early-return defect has been corrected in the current working tree. It must not remain listed as an unresolved default micropore-discharge bug. Legacy macropore activation still follows a separate early-return branch.
  • confirmed mechanismNo aggregate outflow budget. Micropore water-table discharge is uncapped; capped free-drainage calls share the original liquid store rather than a remaining budget. A source-extracted synthetic one-cell, five-face check removed 1.66663 units from one stored unit at NPH = 30. That reproduces conditional overdraw but does not establish its occurrence in an example case. Macropore natural/tile caps also omit previously accepted lateral withdrawals.
  • source behaviorFixed-water-level heat. The boundary helpers do not apply the HeatAdv_scal suppression used by internal Darcy flow. Fixed-water-level mode suppresses boundary water divergence but retains its heat divergence. No fixed-water-level integration test was run here.
  • formulationSign and unit assumptions. Slope corrections occur after one-sided potential clips; do not label all accepted discharge negative or recharge positive without checking the final potential. Input and datatype units disagree for conductivity and face multipliers. Lateral mode-zero dispatch and distance scaling need a design decision.
  • scopeBoundary cells and active depth. Natural/table exchange uses lateral external faces, so interior cells do not directly access tile outlets. Mode 3 omits those pathways. Active-depth conditions differ among gates and are not a blanket exclusion of every layer below zₐ.

Verification for this revision comprises tracing the active formulas, caller order, shared routine use, source links, and arithmetic examples against the current source.
