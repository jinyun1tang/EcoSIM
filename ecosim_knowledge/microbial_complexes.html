Microbial complexes in litter and soil layers

Code-based knowledge note · 18 September 2026 · Sources refer to this repository checkout.

EcoSIM defines five organic matter–microbe complexes. The surface litter layer uses complexes 1–3; non-litter (soil) layers use all five. These are substrate-associated complexes, with microbial biomass and related organic matter pools, rather than individual microbial functional groups.

Source: MicBGCPars.F90, lines 139–167, defines the indices, names, and litter flags. EcoSIMConfig.F90, line 22, sets jcplxc = 5. Layer coverage indicates which complexes are included in the calculation, not that every complex necessarily has nonzero mass.

How the layer selects its complexes

In StageBGCEnvironCondition, the LitrM flag determines the number of organic matter–microbe complexes calculated:

IF (litrm) THEN
  KL = micpar%NumOfLitrCmplxs  ! 3: surface litter layer
ELSE
  KL = micpar%jcplx           ! 5: non-surface soil layer
ENDIF

Source: MicBGCFGMod.F90, lines 380–405. The microbial biomass loop also explicitly excludes k_POM and k_humus when LitrM is true, around lines 488–490.

A non-litter layer is different from a non-litter complex. Soil layers contain litter complexes 1–3 as well as POM and humus. The term “non-litter complexes” refers specifically to indices 4–5. The is_litter flags are true for indices 1–3; is_finelitter is true only for index 2.

Components and autotrophs are separate distinctions

Protein, carbohydrate, cellulose, and lignin are the four substrate components named by kiname, not four additional complexes. Their indices are iprotein = 1, icarbhyro = 2, icellulos = 3, and ilignin = 4. Source: MicBGCPars.F90, lines 150–162.

These chemical component names apply to litter. POM reuses component 1 for a single kinetic fraction; humus reuses components 1 and 2 for less- and more-resistant fractions. See solid organic matter kinetic components for their meanings, partitioning, and decomposition coefficients.

The code also refers to an “autotrophic complex.” Autotrophic microbial biomass is handled separately in mBiomeAutor, without the substrate-complex index K used by mBiomeHeter. It is not another entry in the five-complex table. Source: MicBGCFGMod.F90, the heterotrophic biomass loop around lines 488–525 and autotrophic loop starting at line 528.
